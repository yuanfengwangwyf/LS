Leaderboard 排行榜

用于展示社区或玩家排行信息的业务组件，支持主榜单切换、二级筛选、地区选择、排行条目和未上榜状态配置。

API 参考

战绩排行 · createLeaderboardStandings(options)

参数说明类型可选值默认值
mode默认榜单；战绩页面与本示例共用此组件stringpower | wins | weaponpower
width / height宽度支持 CSS 长度，高度为固定榜单区域；切换与悬浮不改变高度number | string / number-280 / 506
rowsByMode按榜单配置列表，超出可视区域可滚动；value 支持 0object{ power: [], wins: [], weapon: [] }；条目 { rank, name, city, avatar, online, value }每榜 10 条示例
selfByMode各榜单个人排名；悬浮时直接覆盖列表底部，不额外占位object{ power: {}, wins: {}, weapon: {} }；条目 { rank, name, avatar, online, desc, value, label }内置示例
regions / weapons地区和武器下拉选项string[]-湖北等地区 / 突击步枪等类型

onChange筛选变化回调；也触发 leaderboard-change 事件，数据请求由使用方接入function({ mode, period, region, weapon })null
onMore / onRowClick完整榜单入口、玩家点击回调function(state) / ({ row, index, state })null
