Global Search 全局搜索

用于全局搜索游戏、社区和用户。搜索页展示历史记录、活动 Banner、游戏筛选与发行卡片；输入关键词后切换为游戏/社区和用户双栏结果。

API 参考

参数 说明 类型 可选值 默认值
value搜索框默认值；为空展示默认推荐内容，有值展示搜索结果内容string-''
placeholder搜索框占位文本string-''
history历史记录标签文本string[]-英雄联盟 / PUBG / 无畏契约...
games搜索页游戏发行卡片数据object[]-内置 8 条示例数据
results结果页游戏与社区混合数据；通过 type 区分 game / communityobject[]-内置 9 条示例数据
resultCount结果标题中展示的匹配数量number-50
users用户搜索结果数据，头像及在线状态走 Avatar 组件object[]{ name, avatar, gender, nn }内置 8 条示例数据
onClose点击右上角关闭按钮回调function-null
