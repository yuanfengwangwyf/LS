通用/输入框

Input 输入框

输入框用于接收用户文本输入，提供不同的状态反馈帮助用户理解当前输入状态。

交互示例

点击输入框体验交互效果，观察状态变化。

输入框尺寸

输入框定义了两种尺寸（large， default），分别为 40px 和 32px。

输入框状态

输入框的错误状态和禁用状态。

字符限制

输入框右侧显示字符计数，超过限制时显示错误状态。

搜索功能

输入框右侧显示搜索图标，有内容时显示清除图标。

链接复制

输入框左侧显示链接图标，右侧显示复制按钮。

富文本输入框

多行文本输入框，适用于长文本输入场景。

API 参考

参数 说明 类型 可选值 默认值
placeholder 输入框占位文本 string - 'Placeholder'
value 输入框初始值 string - ''
state 输入框状态 string 'default' | 'error' 'default'
size 输入框尺寸 string 'large' | 'default' 'large'
type 输入框类型 string 'default' | 'textarea' 'default'
disabled 是否禁用 boolean true | false false
charLimit 字符限制数量，设置后显示计数 number - null
showSearch 显示搜索图标 boolean true | false false
effect 输入框进入时的视觉效果 string 'none' | 'shine' 'none'
prefixIcon 输入框前置图标 HTML string - null
searchIconHtml / clearIconHtml 搜索态和清空态图标 HTML string - 内置搜索 / 关闭图标
showLinkCopy 显示链接复制功能 boolean true | false false
linkActionText 链接输入框右侧操作文案 string - 'COPY'
linkActionAriaLabel 链接输入框右侧操作的无障碍名称 string - ''
onLinkAction 自定义右侧操作回调；配置后不执行默认复制 function - null
onInput 输入事件回调 function - null
onFocus 聚焦事件回调 function - null
onBlur 失焦事件回调 function - null
onChange 值变化事件回调 function - null
onSearch 搜索事件回调 function - null
onClear 清除事件回调 function - null
onCopy 复制事件回调 function - null
className 自定义类名 string - ''
id 自定义 id string - ''
