数据输入/开关

Switch 开关

开关用于在两个互斥状态之间快速切换，支持不同尺寸、默认样式、带图标样式、密码扩展样式和禁用态。

交互示例

默认样式和带图标样式都支持点击切换，同时展示禁用态效果。

尺寸

开关支持大、中、小三种尺寸，分别对应 48×24、40×20、32×16。

密码样式

扩展样式支持无密码、明文密码、隐藏密码三种展示状态。

API 参考

参数 说明 类型 可选值 默认值
checked 开关是否选中 boolean true | false false
size 开关尺寸 string 'large' | 'default' | 'small' 'large'
state 开关样式类型 string 'default' | 'icon' | 'lock' | 'password' 'default'
passwordState 密码扩展样式的展示状态 string 'empty' | 'filled' | 'hidden' 'empty'
passwordCode 明文密码展示内容 string - '8538'
hiddenCode 隐藏密码的辅助标识文案，仅用于无障碍描述 string - 'hidden password'
disabled 是否禁用 boolean true | false false
onChange 状态切换回调，返回最新 checked 值 function - null
onClick 点击事件回调 function - null
className 自定义类名 string - ''
id 自定义 id string - ''
