数据展示/徽章

Badge 徽标

Badge 用于显示状态或数量提醒，可以独立使用或与其他元素配合使用。

信息提示徽标

用于显示数量，或新消息提示支持不同颜色和大尺寸。

设置 text，可设置自定义提示内容，如 NEW。

variant 可选：red gray black new；red 使用 Esports Blue 品牌色。

size 可选：default small。

在线状态

用于显示在线（绿色）、隐身（橙色）、勿扰（红色）、手机在线状态。

variant 可选：on(在线) inv(隐身) dnd(勿扰) mo(手机在线)。

size：圆点尺寸，数字类型，如 10 14 18。

带描边徽标

数字徽标和圆点徽标支持描边功能，可设置描边大小和颜色。

stroke.size：描边大小，1 2 3。

stroke.color：描边颜色变量，默认 gray-1。

API 参考

参数 说明 类型 可选值 默认值
text 徽章文字 string - ''
variant 徽章颜色/样式 string 'red' | 'gray' | 'black' | 'on' | 'inv' | 'dnd' | 'new' | 'mo' 'red'
size 徽章尺寸 string | number 'default' | 'small' | 数字(圆点/mo徽章) 'default'
dot 是否显示为圆点 boolean true | false false
stroke 描边配置（数字/圆点徽标） object { size: 1|2|3, color: '变量名' } null
