Input Number 数字输入

Input Number 用于精确输入数值，支持键盘输入、点击加减和禁用状态。

交互示例

点击左右按钮或直接输入数值，组件会按步进值更新并限制在可配置范围内。

组件尺寸

提供 Large、default、Small 三种尺寸，对应 Figma 中的三档高度和图标大小。
