Message 消息提示

Message 用于轻量反馈提示，支持 error、success、warning、normal 四种状态，可配置操作按钮和关闭按钮。

基础样式

四种状态对应不同线性图标颜色，容器使用 gray2 背景、gray8 描边和 shadow-sm 阴影。

可配置操作

可按需展示小尺寸操作按钮或关闭按钮；两者互斥，不同时展示。
