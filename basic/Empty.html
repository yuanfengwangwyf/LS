数据展示/空状态

Empty 空状态

Empty 用于在列表、页面或弹窗中展示暂无内容、搜索无结果、网络异常等空状态，可配置图片、文案和操作按钮。

场景分类

按页面场景与浮窗场景分类展示，不传 type 时默认展示通用类型「暂无数据」。

使用

空状态可与按钮组合使用，引导用户直接新建或添加；通过 type 属性调用不同类型的空状态。
