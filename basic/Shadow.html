基础/阴影

Shadow 阴影

阴影通常用来表达界面元素的层级，阴影越重的元素距离用户越近。

shadow-sm

color: var(shadow)
X: 0, Y: 3, B: 6, S: 0

shadow-md

color: var(shadow)
X: 0, Y: 6, B: 18, S: 0

shadow-lg

color: var(shadow)
X: 0, Y: 12, B: 36, S: 0

Token Value
$shadow-sm 0 3px 6px var(shadow)
$shadow-md 0 6px 18px var(shadow)
$shadow-lg 0 12px 36px var(shadow)
