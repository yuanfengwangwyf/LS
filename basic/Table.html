Table 表格

Table 用于展示结构化数据，支持固定表头、纵向滚动、横向滚动、多选列、表头上下排列和单元格自定义组件渲染。

纵向滚动

表头固定在顶部，表体内容纵向滚动；表头高度 40px，表体行高 60px。

横向滚动与固定列

支持同时横向和纵向滚动，可配置固定表头、固定列和右侧操作列。

多选、排序与自定义内容

表头第一列可配置多选，表头支持点击切换排序；单元格内容可插入组件，默认展示 Label。
