Menu 游戏菜单

Menu 用于游戏社区的侧边导航菜单，支持 hover 和 focus 交互状态。

Interactive Menu

移动鼠标到菜单项查看 hover 状态，点击菜单项查看 focus 状态。

API 参考

参数 说明 类型 可选值 默认值
actions 顶部功能入口配置数组；传空数组可隐藏 array - 游戏、申报、我的
actions[].label 功能入口文案 string - ''
actions[].icon 功能入口 iconfont 名称 string - ''
actions[].avatarSrc 功能入口头像地址；设置后优先使用头像 string - ''
actions[].avatarSize 功能入口头像尺寸 number Avatar 支持的尺寸 33.333
actions[].onClick 点击或键盘激活入口时的回调 function - -
selectedActionIndex 默认选中的顶部功能入口索引 number -1 或有效入口索引 -1
items 菜单项配置数组 array - []
items[].type 菜单项类型 string 'icon' | 'text' | 'image' 'image'
items[].icon 图标名称（icon 类型使用） string - ''
items[].text 文本内容（text 类型使用，取首字符显示） string - ''
items[].color 背景颜色（text 类型使用） string - 'var(--gray-4)'
items[].src 图片地址（image 类型使用） string - ''
items[].tooltip 提示文本 string - 'prompt text'
